# Jepang-In — Official Company & App Platform Website

Website profil resmi dan landing page resmi untuk aplikasi pembelajaran bahasa Jepang interaktif berbasis gamifikasi **Jepang-In**.

## 🌟 Fitur Utama Website
1. **Desain Gamifikasi & Tactile 3D**:
   - Skema warna aplikasi asli: *Hinomaru Red* (`#E53935`), *Navy Blue* (`#1A237E`), *Royal Blue* (`#2563EB`), dan *Gold Gamification* (`#FFB300`).
   - Mockup smartphone interaktif yang menampilkan antarmuka aplikasi nyata (Header Stats Pill, Pinned Level Selector, Duolingo Zig-zag Nodes, Peti Harta Karun).
2. **Interactive Roadmap Simulator**:
   - Pengunjung web dapat mengklik level N5 sampai N1, memilih node pelajaran, melihat EXP reward, dan mencoba sensasi petualangan belajar.
3. **Kitsune Mascot Interactive Stage**:
   - Menampilkan maskot resmi aplikasi dengan berbagai ekspresi (Senang, Tekad, Fokus, Gembira, Semangat) yang dapat diklik untuk dialog motivasi langsung.
4. **Download Direct APK**:
   - Tombol unduhan terhubung langsung ke installer resmi `assets/downloads/Jepang-In.apk` (~62.5 MB).
5. **Company Profile & Value**:
   - Profil pengembang, visi misi inklusif, serta FAQ interaktif.

## 📁 Struktur Direktori
```text
oficial-web-company/
├── index.html              # Halaman utama responsif lengkap
├── styles.css              # Styling CSS modern, fluid typography, mobile optimized
├── script.js               # Logika interaktif: Roadmap switcher, Mascot emotion, FAQ
├── README.md               # Dokumentasi website
└── assets/
    ├── downloads/
    │   └── Jepang-In.apk   # File APK resmi aplikasi (62.5 MB)
    └── images/             # Logo resmi dan ragam ekspresi maskot
```

## 🚀 Cara Menjalankan Secara Lokal
Buka berkas `index.html` langsung di browser favorit Anda, atau jalankan melalui local server:
```bash
# Menggunakan Python
python -m http.server 8000
# Lalu buka: http://localhost:8000
```
